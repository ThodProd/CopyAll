# CopyAll

Утилита Windows: список файлов и структура папки, копирование и экспорт в текст.
Версия для ThodHUB работает внутри хаба и хранит настройки в его папке Data/copyall.
Исполняемая часть — отдельный .NET-процесс; установленный SDK пользователю не нужен.

В `standalone` сохранён исходный самостоятельный WPF-проект. Его интеграция с
контекстным меню не вызывается при установке пакета хаба.

## Сборка модуля

`dotnet publish hub/CopyAll.Worker.csproj -c Release -r win-x64 --self-contained true -o artifacts/package/worker`

Положить `hub/manifest.json` в корень пакета, содержимое `hub/ui` в `ui` и SDK
`thodhub.js` из ThodHUB в `ui/thodhub.js`. Архивировать содержимое папки package.
Пакет содержит готовый runtime. Реестровые записи и права администратора не нужны.

Сканирование не меняет файлы, пропускает ссылки и junction, ограничено 20 000
элементов, 64 уровнями вложенности и 2 МБ результата. Недоступные папки учитываются
как пропущенные. Публичный репозиторий не содержит пользовательские списки файлов.
