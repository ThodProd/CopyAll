# CopyAll

CopyAll добавляет в Проводник Windows пункт «Копировать полный путь» с собственной иконкой. Для файла копирует абсолютный путь. Для папки собирает пути самой папки, всех вложенных каталогов и файлов, включая скрытые элементы. На Windows 11 пункт доступен для выбранных файлов и папок в первом меню. Классическое меню также поддерживает фон папки и диски.

В настройках CopyAll в ThodHUB четыре кнопки для добавления и удаления меню и автозапуска. При включённом автозапуске CopyAll проверяет регистрацию классического меню при входе в Windows и завершает работу. Копирование из Проводника доступно при закрытом хабе. При обновлении пути включённых регистраций перенастраиваются на новую версию. При удалении модуля хаб убирает меню и автозапуск.

## Большие папки

Ограничений на количество элементов, глубину вложенности и размер списка в CopyAll нет. Большой список пишется на диск по мере обхода. Если Windows не принимает его в буфер обмена, CopyAll сохраняет полный результат в `%TEMP%\CopyAll` и открывает TXT в программе Windows по умолчанию. Содержимое исходных файлов не читается. Вложенные точки повторной обработки, включая ссылки на каталоги и junction, попадают в список без обхода их содержимого, чтобы исключить циклы. О недоступных элементах CopyAll сообщает после операции.

## Windows 11

Первое меню использует подписанный пакет MSIX и небольшое расширение Проводника на Rust. Если сертификату издателя ещё не доверяет Windows, кнопка «Добавить в контекстное меню» предлагает добавить его в «Доверенные лица» компьютера. Требуется подтверждение UAC. Классическое меню работает сразу. Доверие сертификату сохраняется после удаления для будущих установок. Отпечаток издателя **0E85D468BD75DF47E5B93DBE77C5141A2B6BCFED**.

## Сборка

Для компиляции нужны Rust stable x64 и инструменты соответствующего Windows toolchain. При сборке GNU требуется `windres`. Релизный EXE и расширение собираются командой `cargo build --workspace --locked --release`. На компьютере пользователя отдельный Rust или .NET runtime не нужен.

Для подписанного пакета ThodHUB запустите PowerShell 7 из корня проекта:

```powershell
./hub/build.ps1 -HubRoot <путь-к-ThodHUB> -SdkTools <папка-с-MakeAppx-и-SignTool>
```

Скрипт использует открытый сертификат из репозитория и ключ подписи автора в `CurrentUser\My`. Ключ остаётся на машине автора. Итоговый ZIP и дескриптор с SHA-256 и размером находятся в `artifacts/hub-release/2.0.0`. GitHub Actions проверяет сборку Rust. Подписанный ZIP собирается на машине с ключом.
