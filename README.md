# CopyAll

Утилита Windows: список файлов и структура папки, копирование и экспорт в текст.
Версия для ThodHUB работает внутри хаба и хранит настройки в его папке Data/copyall.
Исполняемая часть — отдельный .NET-процесс; установленный SDK пользователю не нужен.

В `standalone` сохранён исходный самостоятельный WPF-проект. Его интеграция с
контекстным меню не вызывается при установке пакета хаба.

## Сборка модуля

`dotnet publish hub/CopyAll.Worker.csproj -c Release -r win-x64 --self-contained true -o artifacts/package/worker`

Положить `hub/manifest.json` в корень пакета, содержимое `hub/ui` в `ui` и SDK
`thodhub.js` из ThodHUB в `ui/thodhub.js`. Архивировать содержимое папки package.
Пакет содержит готовый runtime. Права администратора не нужны. В версии 1.1.0 кнопки интерфейса управляют пунктами меню в HKCU/Software/Classes. Чужие пункты меню не меняются.

Сканирование не меняет файлы, пропускает ссылки и junction, ограничено 20 000
элементов, 64 уровнями вложенности и 2 МБ результата. Недоступные папки учитываются
как пропущенные. Публичный репозиторий не содержит пользовательские списки файлов.

## Обновление 1.1.0
Встроены установка и удаление контекстного меню для папок и их фона. «CopyAll — копировать все пути» копирует абсолютные пути рекурсивно. В Windows 11 откройте «Показать дополнительные параметры». Команда вызывает текущую версию через ThodHUB; деинсталляция убирает только ключи CopyAll с собственным маркером.

## Windows 11 и сборка 1.1.2
Включает нативный IExplorerCommand и подписанный identity-пакет ThodProd.CopyAll. Первичная установка через интерфейс CopyAll требует явного согласия на сертификат ThodProd.CopyAll в LocalMachine/TrustedPeople и UAC. Корневые сертификаты не меняются. Доверие сохраняется после удаления для будущих установок; удалить его можно в certlm.msc → Доверенные лица (отпечаток 0E85D468BD75DF47E5B93DBE77C5141A2B6BCFED). Закрытый ключ неэкспортируемый, находится только у автора в CurrentUser/My. В Git публикуется открытый CER.
Сборка hub/build.ps1 принимает HubRoot, Compiler (clang++ llvm-mingw), SdkTools (MakeAppx/SignTool), SigningThumbprint. Компилятор переносимый; глобальные PATH и зависимости Windows не изменяются. Повторная сборка выпуска требует ключ подписи автора. Поднимайте одновременно версии csproj, manifest.json, app.manifest, shell/AppxManifest.xml и ShellIntegration.cs. Пакет не заменяется после публикации.
Современное меню работает для выбранных папок и файлов; классическое также для фона папки и дисков. Обход дерева выполняется отдельным worker, Проводник не блокируется. Запуск из меню не требует открытого хаба.
